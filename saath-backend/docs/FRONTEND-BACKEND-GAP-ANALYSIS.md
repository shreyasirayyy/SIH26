## Important audit findings

The ZIP contains imports such as `@/services/case`, `@/services/ai`, and `@/services/notifications`, while the repository inventory is inconsistent about those abstractions. Regardless, there is no configured API base URL, fetch/axios client, access-token lifecycle, or server authentication integration. The clean integration point is a small new frontend `lib/api.ts` plus targeted replacement of service implementations; the visual components and routes can remain unchanged.

The prototype uses a synthetic NHAA docket such as `NHAA-RJ-2026-004821`. The backend preserves this demo behavior through a clearly labeled synthetic adapter. OTP is never simulated.
